# Roadmap

The portfolio is built in phases. A phase is complete only when every project in it passes the quality gates in [ARCHITECTURE.md](ARCHITECTURE.md).

## Phase 1 — Research ✅
Survey of the 2026 landscape: AI/LLM engineering practices, modern full-stack, backend patterns, DevOps tooling, mobile, free-tier deployment options, and what separates strong GitHub profiles from generated noise. Output: [docs/RESEARCH.md](docs/RESEARCH.md), [docs/PORTFOLIO-BENCHMARK.md](docs/PORTFOLIO-BENCHMARK.md).

## Phase 2 — Final project list ✅
Roughly 30 projects selected and ranked. Output: [PROJECTS.md](PROJECTS.md).

## Phase 3 — Foundation
This repository, engineering conventions, shared CI templates, git identity verification.

## Phase 4 — Flagship wave
The first 5 projects, one per major category, built to the full quality bar:
backend (Go), AI/LLM (Python), open-source tool (TypeScript), distributed/real-time, full-stack SaaS.

## Phase 5 — Verification & deployment
CI green everywhere, Docker images build, live demos for projects that fit free tiers, honest deployment guides for the rest.

## Phase 6 — Second wave
Remaining AI, full-stack, and backend projects.

## Phase 7 — Mobile, DevOps, security wave
Flutter and Kotlin apps (CI-built), observability lab, GitOps lab, security tooling.

## Phase 8 — Portfolio website
Improve the existing live site [aminyx.top](https://aminyx.top) (project filters, case studies, links to new repositories) rather than building a duplicate site.

## Phase 9 — GitHub cleanup
Pinned repositories, topics, descriptions, archiving or hiding empty repos, profile README refresh with real featured projects.

## Phase 10 — Final audit
Every link, badge, demo, and claim verified. Output: FINAL-PORTFOLIO-AUDIT.md.
